# Methodology

Legend Saju treats a traditional system as a versioned rule set rather than prose
that a model may improvise.

## Layers

1. Calendar and birth-input audit
2. Deterministic system calculators
3. Lineage-specific doctrine evaluators
4. Claims, conflicts and time windows
5. Optional explanation by an application

An application may summarize an engine result. It must not invent a missing
pillar, unsupported formula, source, or claim.

## Uncertainty

Unknown birth time is represented as candidate charts. Different schools stay
different. A blocked calculation remains blocked. No layer converts those
states into artificial confidence.

## Verification vocabulary

- `verified_calculation`: source or independent implementation fixtures close the implemented formula.
- `bounded_calculation`: a reproducible subset is implemented and omitted dimensions are named.
- `heuristic`: an engineering or interpretive rule that is not a closed classical formula.
- `experimental`: useful for inspection, not a primary claim.
- `knowledge_only`: source material without an executable calculator.

These labels describe software provenance, not scientific validation of
divination.
