# Capability boundary

The runtime registry returned by `getEngineManifest()` is authoritative.

Every capability records:

- system and lineage;
- maturity and evidence role;
- required inputs;
- source IDs;
- omitted dimensions;
- preflight status.

The public source contains 26 compatibility intents and a deeper question-first
dossier. Some systems are deliberately bounded. In particular, the repository does
not contain an invented Tieban prose corpus, automatic birth-time truth selector,
universal fate score, or guaranteed event predictor.

The public GitHub source includes the source-audited Korean court-name compilation
and the separate Tieban question-time numeric table path. Their provenance,
retrieval boundaries, and third-party notices remain explicit; neither layer is
presented as a scientifically validated prediction or a substitute for a current
official name-eligibility check.
